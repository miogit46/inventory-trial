# Toko Alat Musik — GitHub Pages

Aplikasi HTML katalog dan stok toko alat musik yang dapat dipasang dari browser dan digunakan offline setelah dibuka sekali.

## Membuka dan memasang

Buka <https://miogit46.github.io/inventory-trial/trial-2026/> melalui Chrome, lalu pilih **Instal aplikasi** atau **Tambahkan ke layar utama** dari menu browser.

## Data dan privasi

Aplikasi memuat 919 produk bawaan dari template. Data produk yang diedit disimpan di browser pada perangkat masing-masing dan tidak tersinkron otomatis. Repositori dan situs GitHub Pages bersifat publik; katalog, harga, dan stok bawaan di dalam berkas HTML dapat dilihat siapa saja.

## Memperbarui

Unggah versi terbaru `index.html` ke folder `trial-2026` pada branch `main`. Naikkan versi cache pada `service-worker.js` setiap kali app shell berubah agar perangkat mengambil versi baru.
