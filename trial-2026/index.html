Keamanan & PIN

PIN Admin dibuat saat pengaturan awal. Admin dapat membuat PIN User dan PIN Edit Gudang di sini. PIN terdiri dari 4 huruf/angka; huruf besar dan kecil dianggap sama.

PIN disimpan sebagai hash. Karena aplikasi berjalan lokal di browser, PIN ini merupakan pengaman operasional dan tidak dapat mencegah bypass melalui alat pengembang.

Instalasi

Pasang aplikasi ke perangkat agar dapat dibuka dari layar utama dan digunakan kembali tanpa koneksi setelah pertama kali dimuat.
